Sources & data

The public website reads data/snapshots.json. All visitors see the same published dataset. Local file imports are a preview only and are not shared with other visitors.

CSV columns: snapshot_date, player_id, name, server, alliance, hero_power, kills, rank. Each snapshot should include the Top 200 by THP per server. A blank kills value means unknown, not zero.
